
# The Whispering Woods 

This is a short-story that takes you through a very brief adventure in a place called the Whispering Woods in order to complete a task. This adventure based story was created using Java.

You must run the program in Visual Studio Code. You can find the necessary Java extension here: https://code.visualstudio.com/docs/java/extensions. In addition, please execute the Java Coding Pack that was included with the other files.

In order to run the story, open the program in Visual Studio Code and select the “run” button at the top-right of the screen. At the start, the story will ask you several questions that prompt you to enter your name, preferred pronouns, and your age. From there, you will be asked to make decisions to direct your character through the story.
